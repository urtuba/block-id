# Hinance (2023 prototype, kept as reference)

The demo exchange front end of the ETHGlobal Istanbul hackathon project (November 2023): a React app (create-react-app, MUI, wagmi and ConnectKit) styled like a crypto exchange. It had a login and register page, a KYC page, a "Continue with BlockID" step that sent the transaction to the zkSync contract, and a success page. It talked to `client-server` and to the zkSync Era Goerli contract.

**This folder is not maintained, and it does not work any more.** The chain, the contract address and the backend it used are gone.

A browser demo that runs the restored protocol (real proofs and an in-browser EVM, with three exchanges in this style) is planned to replace it.

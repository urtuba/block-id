What you are about to see

A user passes KYC at Violex and Mintex. Later, at Hinance, the user clicks Continue with BlockID and Hinance gets the verified identity. BlockID checks that both exchanges know the same person, using zero-knowledge proofs, and never sees a name or an ID number.

It all runs in this tab: a small blockchain, the real BlockID contract, real Groth16 proofs, and the real protocol code from this repository. No wallet, no test ETH, no server. Nothing you do here leaves your browser.

    How this demo works

    • The chain is Tevm, an EVM written in JavaScript, started in this tab. The contract is the one in contracts/; the page deploys it on load.
    • The proofs are made in your browser with snarkjs from the files in circuits/artifacts/, and checked twice: by BlockID's code, then by the contract.
    • The demo wallet is a random key made on this page. It lives in memory only and is gone when you close the tab.
    • On a real network the sync would be public: observers would see the wallet, the exchanges and the commitment. Here, nothing leaves your browser.
    • The look of the exchange comes from the 2023 hackathon front end. The favicon is by Oguz Dogan.
